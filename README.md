# Hospital Management System

## Project Description

Hospital Management System is a web-based application designed to manage hospital activities including patient registration, doctor management, appointments and medical records.

## Frontend Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

Hospital-Management-System-Frontend

- index.html
- style.css
- script.js


## How to Run

1. Download the project.
2. Open index.html in any browser.

## Features

- Patient Registration UI
- Hospital Services Dashboard
- Responsive User Interface
- Simple Navigation
